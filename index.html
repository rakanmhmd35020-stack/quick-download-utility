Privacy Policy for Quick Download Utility

Last updated: October 29, 2026

Quick Download Utility is a browser extension designed to help users detect downloadable media on webpages and send the selected download information to the Quick Download Utility desktop application.

1. Information We Process

The extension may process the following information only when necessary to provide its core functionality:

  • The URL of the currently active webpage.
  • Media-related information available on the current webpage.
  • Download-related information such as media type, format, quality, file type, and the option selected by the user.
  • Connection status between the browser extension and the Quick Download Utility desktop application.

2. How We Use Information

  • Detect downloadable media on supported webpages.
  • Display available download formats and quality options.
  • Send a download request selected by the user to the Quick Download Utility desktop application.
  • Maintain and confirm local communication with the desktop application.

3. Local Desktop Communication

The extension communicates with the Quick Download Utility desktop application through a local connection on the user's own computer.

http://127.0.0.1:17835

This local connection is used only to exchange information necessary for download-related functionality between the browser extension and the desktop application.

4. Data Collection and Storage

Quick Download Utility does not intentionally collect or store personal information on an external server as part of the extension's normal operation.

Page URLs and media-related information may be processed temporarily when required to provide the requested download functionality.

5. Data Selling and Advertising

  • We do not sell user data.
  • We do not use user data for advertising.
  • We do not use browsing activity for profiling.
  • We do not share user data with third parties for marketing purposes.

6. Browser Permissions

The extension may request browser permissions that are necessary to provide its download-related functionality.

These permissions may be used to:

  • Access the active browser tab when required.
  • Detect downloadable media on supported webpages.
  • Store extension settings locally in the browser.
  • Manage downloads initiated by the user.
  • Schedule extension background tasks.
  • Communicate with the Quick Download Utility desktop application on the user's local computer.

Browser permissions are used only for the functionality described in this Privacy Policy.

7. Remote Code

Quick Download Utility does not intentionally download or execute remote JavaScript code.

Executable extension code is included within the extension package.

8. User Accounts

The extension does not require users to create an account or sign in to use its core functionality.

9. Third-Party Websites

Quick Download Utility may detect downloadable content on third-party websites.

Users are responsible for complying with the terms of service, copyright rules, and applicable laws of the websites and content they access or download.

Quick Download Utility is not affiliated with third-party websites unless explicitly stated.

10. Security

Reasonable measures are used to limit communication to the local Quick Download Utility desktop application and to avoid unnecessary processing of user information.

However, no software or data transmission method can be guaranteed to be completely secure.

11. Children's Privacy

Quick Download Utility is not specifically directed toward children and does not intentionally collect personal information from children.

12. Changes to This Privacy Policy

This Privacy Policy may be updated when the extension's features, permissions, or data practices change.

The "Last updated" date at the top of this page will be revised when changes are made.
